# Pixel Music

**A Material 3 Expressive music player for the desktop.**
Stream YouTube Music, play lossless FLAC, sing along with synced lyrics.

[![Release](https://img.shields.io/github/v/release/Rajat-Solankii/PixelMusic?include_prereleases&label=release)](https://github.com/Rajat-Solankii/PixelMusic/releases)
[![License: GPL-3.0](https://img.shields.io/badge/license-GPL--3.0-blue)](LICENSE)

</div>

This repository holds the **releases** of Pixel Music for desktop, the place to **report problems**, and the license
files. The app checks this repository for updates.

## Features

- YouTube Music: home shelves, search, playlists, sign-in, listening history sync
- Lossless FLAC (Monochrome) and JioSaavn streams, downloads for offline listening
- Synced lyrics (word by word where available), lyrics search on LRCLIB, .lrc import and export, sync offset
- Romanization under Hindi, Punjabi, Korean, Japanese kana, Cyrillic and Greek lyrics
- Dynamic colour from the album art, light and dark themes, Google Sans Flex
- Your Mix, Daily Mix, Recently played, listening stats, queue history with *Replay queue*
- Equalizer, sleep timer, mini player, floating island, Last.fm scrobbling
